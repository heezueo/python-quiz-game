# 🐾 동물 퀴즈 게임

## 📖 프로젝트 개요

Python으로 개발한 콘솔 기반 퀴즈 게임입니다.

사용자는 동물과 관련된 퀴즈를 풀고, 새로운 퀴즈를 직접 추가할 수 있습니다.
프로그램을 종료한 후에도 퀴즈와 최고 점수가 JSON 파일에 저장되어 유지됩니다.

이 프로젝트를 통해 Python의 클래스, 객체지향 프로그래밍, 파일 입출력(JSON), 예외 처리, Git 사용법을 학습하였습니다.

---

## 🦁 퀴즈 주제 선정 이유

동물은 누구나 친숙하게 접할 수 있는 주제이며,
다양한 문제를 쉽게 만들 수 있어 퀴즈 게임의 주제로 선정하였습니다.

---

## ▶ 실행 방법

프로젝트 폴더에서 아래 명령어를 실행합니다.

```bash
python3 main.py
```

## ✨ 기능 목록

- 퀴즈 풀기
- 새로운 퀴즈 추가
- 등록된 퀴즈 목록 보기
- 최고 점수 확인
- 프로그램 종료
- 퀴즈 및 최고 점수 자동 저장(JSON)
- 프로그램 실행 시 저장된 데이터 자동 불러오기
- 예외 처리

  - 잘못된 정답 입력
  - Ctrl+C 종료 처리
  - EOFError 처리
  - 파일이 없거나 손상된 경우 처리

## 💾 데이터 파일(state.json)

프로그램에서 사용하는 데이터를 저장하는 파일입니다.

경로

```
state.json
```

저장 내용

- quizzes : 등록된 퀴즈 목록
- best_score : 최고 점수

예시

```json
{
    "quizzes": [
        {
            "question": "판다가 주로 먹는 음식은 무엇일까요?",
            "choices": [
                "사과",
                "대나무",
                "고기",
                "옥수수"
            ],
            "answer": 2
        }
    ],
    "best_score": 5
}
```
